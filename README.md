ComputerMiner – Virtual Mining Workbench for Minecraft

ComputerMiner lets players assemble virtual mining rigs inside a GUI. Build your own miner by installing CPU, GPU, RAM, motherboard, power supply, and storage drives – each with custom stats. The miner automatically generates in-game currency over time (configurable interval). You can withdraw earnings to Vault economy, view stats via PlaceholderAPI placeholders, and enjoy full multilingual support (zh_cn/en_us). OP commands allow hardware management, balance editing, and viewing other players' rigs.

Features:

Drag-and-drop hardware assembly GUI

Realistic mining yield formula (hashrate × time × RAM multiplier × global rate)

Offline catch-up earnings

Supports custom YAML hardware configurations

Anti-cheat: anvil rename protection, stacked-item prevention

Vault economy integration

PlaceholderAPI variables (see full list below)

Fully translatable messages (language files)

Console colored logs and ASCII banner

Commands:

/com open – Open assembly table (players)

/com take <amount> – Withdraw miner balance to Vault cash

/com get <type> <id> – Get a hardware item (OP)

/com set <player> <amount> – Set player's miner balance (OP)

/com inv <player> – Edit another player's miner (OP)

/com reload – Reload config & hardware (OP)


Permissions:

computerminer.use – Allows /com open (default true)
